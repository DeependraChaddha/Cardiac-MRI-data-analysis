# Cardiac-MRI-data-analysis
Analysing Kaggle ACDC dataset which contains cardiac MRI images of 150 patients. Attempting to visualize the data and train a neural network to learn the segmentation of RV,LV and Myocardium
## data-visualization.ipynb 
Makes interactive 3d visualizations of heart from MRI slices.
## acdc-dataset-simple-u-net.ipynb
Made a simple U-net neural network and trained for 20 epochs to learn segmentation of LV, RV and Myocardium. Got 99.1% accuracy on testing dataset.
